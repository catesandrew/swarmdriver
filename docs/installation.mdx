## Packages

Swarmdriver ships as several packages under the `@caps` scope rather than one
`swarmdriver` package. Install only what you need:

| Package | What it is | Needed when |
|---------|------------|-------------|
| `@caps/core` | `buildWdioConfig()`, the config matrix, helpers, and the provider registry | Always |
| `@caps/providers` | Cloud-grid provider implementations (Sauce Labs) | Running against a cloud grid |
| `@caps/reporters` | WebdriverIO reporters (spec, junit, ReportPortal, Sauce comments) | Customising reporters directly |
| `@caps/cli` | `swarm-*` CLI tools and pinned `wdio`/`appium`/`allure` proxies | Using the CLI tooling |

:::warning Upgrading from the single `swarmdriver` package

`@caps/core` ships **no** providers. If you use `remote: 'saucelabs'` you must
also add a bare side-effect import of `@caps/providers` — otherwise
`buildWdioConfig()` returns `undefined` with no error. See
[Quick Setup](#quick-setup) below and the [Providers](./providers.mdx) page.

:::

## Dependencies

Swarmdriver requires the following peer dependencies to be installed:

- **WebdriverIO 9.x** — The core test framework
- **Appium 2.x** — For native mobile app automation
- **Node.js 16+** — The runtime

If you plan to run tests locally on mobile devices, you'll also need:

- **Appium** — Can be installed locally or run as a service
- **Chromedriver** — For Android Chrome browser testing
- **Simulator/Emulator runtimes** — For iOS/Android emulation

For cloud testing with Sauce Labs:

- No additional setup required — just set `WDIO_REMOTE=saucelabs` and provide credentials

## Quick Setup

After installation, create a `wdio.conf.js` in your project root:

```javascript
// Side-effect import: registers the cloud providers (e.g. 'saucelabs') into
// @caps/core's registry. Omit it and remote: 'saucelabs' resolves to nothing.
// Safe to keep even for local-only runs.
import '@caps/providers'
import { buildWdioConfig } from '@caps/core'

// Build your config from the matrix
const config = buildWdioConfig({
  envs: process.env,
  remote: process.env.WDIO_REMOTE || 'local',
  scope: process.env.WDIO_SCOPE || 'browser',
  metal: process.env.WDIO_METAL || 'desktop',
  framework: 'jasmine',
})

export default config
```

Then run tests with:

```bash
# Local desktop browser testing (default)
wdio

# Local mobile device browser testing
WDIO_METAL=device wdio

# Local native app testing
WDIO_SCOPE=app wdio

# Cloud (Sauce Labs) testing
WDIO_REMOTE=saucelabs wdio
```
